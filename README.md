# FlutterLab2

Проект представляет собой консольный менеджер задач (CLI), написанный на языке Dart в рамках изучения основ объектно-ориентированного программирования (ООП). Приложение поддерживает добавление, просмотр, отметку выполнения и удаление задач, а также использует пакет `ansicolor` для стилизации вывода.

## Запуск
1. Клонировать репозиторий: `git clone <url_вашего_репозитория>`
2. Перейти в папку проекта: `cd lab2_todo`
3. Установить зависимости: `dart pub get`
4. Запустить приложение: `dart run`

## Что изучили
1. Создание классов, объявление явных типов полей и инкапсуляцию данных в Dart.
2. Работу со специальными методами: краткими конструкторами, инициализаторами полей и именованными параметрами.
3. Переопределение встроенных методов (в частности, `toString()`) с помощью аннотации `@override`.
4. Применение статических полей класса для реализации глобальных счетчиков и логики генерации ID.
5. Интеграцию и использование внешних пакетов из экосистемы `pub.dev`.

## Ответы на вопросы

1. **В чём разница между полем класса и обычной переменной в функции?**
   Переменная внутри функции существует только во время выполнения этой функции и удаляется из памяти сразу после её завершения. Поле класса принадлежит конкретному созданному объекту и хранит состояние его данных на протяжении всей жизни этого объекта.

2. **Что такое конструктор и зачем он нужен?**
   Конструктор — это особый метод класса, который автоматически вызывается в момент создания нового экземпляра объекта. Он необходим для первоначальной инициализации объекта и заполнения его полей корректными стартовыми значениями.

3. **Зачем нужен @override перед toString()? Что будет если его убрать?**
   Аннотация `@override` явно сообщает компилятору, что мы намеренно переписываем реализацию метода `toString()`, унаследованного от базового класса `Object`. Если убрать аннотацию, код всё равно скомпилируется, однако `@override` защищает разработчика от случайных опечаток в имени метода во время компиляции.

4. **Чем статическое поле static int _counter отличается от обычного поля? Сколько копий этого поля существует в программе?**
   Обычное поле создается заново для каждого отдельного экземпляра объекта (у каждого объекта своя копия). Статическое поле принадлежит самому классу, а не его объектам. В программе всегда существует ровно одна копия статического поля, общая для абсолютно всех объектов этого класса.

5. **Что означает нижнее подчёркивание в _counter?**
   В языке Dart нижнее подчёркивание перед именем идентификатора (переменной, поля или метода) реализует механизм приватности на уровне файла (библиотеки). Поле `_counter` невозможно вызвать или изменить из других файлов проекта, кроме `lib/todo.dart`.
